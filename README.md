# Enterprise Infrastructure Monitoring & Incident Management Platform

An enterprise-grade, end-to-end infrastructure monitoring and IT incident management platform designed for NOC engineers, system administrators, and infrastructure monitoring architects.

## Project Status

- [x] **Phase 1: Environment Setup & Foundation**
- [x] **Phase 2: Core Architecture & PostgreSQL Schema**
- [x] **Phase 3: Prometheus & Exporter Configuration**
- [ ] **Phase 4: Alert Rules & Alertmanager Setup**
- [ ] **Phase 5: FastAPI Backend & Automated Incident Engine**
- [ ] **Phase 6: Custom Web Portal & Operations UI**
- [ ] **Phase 7: Grafana Executive & Operational Dashboards**
- [ ] **Phase 8: Infrastructure Simulation & Runbooks**
- [ ] **Phase 9: End-to-End Testing & Verification**
- [ ] **Phase 10: Complete Enterprise Documentation & Portfolio Assets**

## Technology Stack

- **Metrics Collection & Scrape Engine**: Prometheus
- **Host & HTTP Exporters**: Node Exporter, Blackbox Exporter
- **Alert Dispatcher**: Alertmanager
- **Incident & Automation Backend**: Python (FastAPI), SQLAlchemy, Pydantic
- **Datastore**: PostgreSQL
- **Visualization**: Grafana & Custom NOC Web Portal (HTML5, Bootstrap, Vanilla JS)
- **Containerization**: Docker & Docker Compose
